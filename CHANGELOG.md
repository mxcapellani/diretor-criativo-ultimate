### Known limitations

- No direct image or video generation.
- No verified external generation API integration.
- Platform creative profiles are not vendor API schemas.
- Runtime behavior depends on the hosting language model.
- Image-reference analysis requires a capable host.
- Full equivalence with the original agent is not established.
